# Getting help

- **Documentation:** the [README](README.md) and [`docs/`](docs/); also `diskdiet --help`
  and `diskdiet <command> --help`.
- **Questions & ideas:** [GitHub Discussions](https://github.com/roystondwork-dev/diskdiet/discussions).
- **Bugs:** [open an issue](https://github.com/roystondwork-dev/diskdiet/issues/new/choose) with the output of `diskdiet version --json`.
- **Security issues:** follow [SECURITY.md](SECURITY.md); please don't file them publicly.

diskdiet is maintained by volunteers; there is no guaranteed response time.
