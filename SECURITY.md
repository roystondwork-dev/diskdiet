# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/roystondwork-dev/diskdiet/security/advisories/new),
not in a public issue. You'll get an answer within a week.

diskdiet deletes files, so reports where it could remove anything outside the
cache folders it reports, or follow a symlink out of one, are especially welcome.
